# Complementary mechanistic and observational routes

A vector schematic of the two HRRI routes. The response curve and
biological symbols are illustrative, not measured or simulated
observations. Electron accepting and donating capacities must remain
directionally separate.

## Usage

``` r
plot_rri_framework(base_size = 10)
```

## Arguments

- base_size:

  Base font size in points.

## Value

A ggplot object; export at approximately 7.4 by 4.8 inches.

## Examples

``` r
plot_rri_framework()
```
